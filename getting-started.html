Getting Started

From a fresh import to a fully translated table. This page is the fast path — each step links to the page that covers it in depth.

Requirements
Unity6000.3 or newer
Unity Localization packagecom.unity.localization, installed via Package Manager. Required for StringFlow Translate and StringFlow Environment Setup. StringFlow Tables works without it.
Docker DesktopFree from docker.com. Only needed for StringFlow Translate — the translation server runs inside it, on your machine.
Disk space~4 GB free, for the server image and its language models (downloaded once).
Time, first run only~20–30 minutes of unattended downloading.

⚠ On macOS, one thing to know before you start

macOS reserves port 5000 for AirPlay Receiver — the same port the default translation server wants. Either turn off AirPlay Receiver under System Settings ▸ General ▸ AirDrop & Handoff, or change the server's port later in StringFlow Routing. Details on the Troubleshooting page.

The fast path

  1. Install Docker Desktop and start it. Wait until it reports it's running. See StringFlow Environment Setup.
  2. Open Tools ▸ StringFlow ▸ StringFlow Environment Setup and press Start Setup. It checks Docker, then walks you through installing the LibreTranslate engine — free, ~50 languages, no licence decision needed. Skip NLLB unless you specifically need it (see Licensing).
  3. Let the first download finish. The server downloads its language models once — roughly 20–30 minutes, unattended. The row shows live progress the whole time. Don't interrupt it; see Troubleshooting if you do.
  4. Open Tools ▸ StringFlow ▸ StringFlow Translate. Press Test All to confirm the connection, then set Table, Source Language, Target Language and Translation Type, and press Translate. Full walkthrough on StringFlow Translate.
  5. Before all that — if your text isn't in String Tables yet, open Tools ▸ StringFlow ▸ StringFlow Tables first to find and link it. See StringFlow Tables.

What "safe" means here

Both StringFlow Tables and StringFlow Translate are built around the same rule: they only ever act on what's missing or explicitly selected. StringFlow Translate never overwrites a cell that already has a value — machine-made or hand-written — so re-running a translation pass is always safe. StringFlow Tables' cleanup actions (removing unused keys, clearing values) always show you exactly what will change before anything happens, and everything goes through Unity's Undo system.
