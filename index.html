Runs entirely on your machine — no account, no API key

Every string found.
Every language filled in.
Without leaving Unity.

StringFlow is three tools that share one job: get every piece of text in your project into Unity's own Localization Tables, then get every table translated — using a machine-translation server that runs on your own computer, not someone else's cloud.

One workflow, three tools

Each does one part of the job and hands off cleanly to the next. Use any of them alone, or run all three back to back.

STEP 1

StringFlow Tables

Finds hardcoded text across every scene and prefab, links it to a table, and audits coverage, duplicates, and unused keys.

Explore StringFlow Tables → STEP 2

StringFlow Translate

Fills every empty cell using a local machine-translation server. Never overwrites a value that's already there.

Explore StringFlow Translate → STEP 0

StringFlow Environment Setup

Installs and runs the translation server(s) in Docker on your machine, with one-click repair when something breaks.

Accounts required

Languages, out of the box

LibreTranslate covers ~50 languages after one free setup. An optional second engine extends that further.

1

Rule that never breaks

Translate only ever fills empty cells. Re-running a pass is always safe — nothing you or a human translator wrote is ever replaced.

Open by design
